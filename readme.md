# Demo for webinar about 4D sessions 


Minimum 4D version required: **4D 21 R3**

**Steps to start the application:**

- Open the project on 4D Server
- Connect the remote 4D client
- Create some data by running the **ImportData** method (using the [Execute method dialog box](https://developer.4d.com/docs/Project/project-method-properties#from-the-execute-method-dialog-box))
- Run the 4D remote client application by running the **Run** method (using the [Execute method dialog box](https://developer.4d.com/docs/Project/project-method-properties#from-the-execute-method-dialog-box))
